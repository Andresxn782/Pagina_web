Cuentas Claras

Control de gastos personales · PHP sin frameworks

Cada usuario se registra, apunta sus ingresos y gastos y ve un resumen de cada mes con una gráfica de en qué se le va el dinero. Los movimientos se filtran por mes y categoría y se exportan a CSV.

Cuidé la seguridad desde el principio: consultas preparadas con PDO, contraseñas cifradas, protección CSRF en los formularios y escapado de datos contra XSS.

mesa-libre.test/plano

Mesa Libre

Gestor de reservas para restaurantes · Laravel

Nace de mi trabajo en sala. El personal crea, edita y cancela reservas, consulta las de cada día y ve un plano de la sala que marca qué mesas están libres, reservadas u ocupadas a cualquier hora.

La validación aplica las reglas de un restaurante real: no deja sentar a más personas de las que caben en la mesa ni reservar una mesa que ya está ocupada en esa franja. Las reservas se cancelan en lugar de borrarse, para conservar el historial.

andresxn782.github.io/brisa

Brisa

App del tiempo con API pública · JavaScript

Busca cualquier ciudad y muestra el tiempo actual, las próximas 12 horas y los próximos 5 días. Consulta la API de Open-Meteo con fetch y async/await, y avisa con mensajes claros si la ciudad no existe o no hay conexión.

Recuerda la última ciudad buscada y cambia los colores según la hora local de esa ciudad: mañana, tarde, atardecer o noche. Pensada primero para móvil.

  • JavaScript
  • Fetch API
  • localStorage
  • CSS responsive

Club Remo

Web e inscripciones para un club deportivo · PHP + MySQL

Web del club con horarios, cursos e inscripciones online. Cada curso muestra las plazas libres en tiempo real, y el personal del club confirma o cancela inscripciones y ajusta las plazas desde un panel privado.

Al inscribir uso una transacción con SELECT … FOR UPDATE: si dos personas intentan coger la última plaza a la vez, nadie se pasa del límite.
