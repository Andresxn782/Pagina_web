Focusly App

Qué es: Aplicación de productividad que ayuda a organizar tareas, planificar el día y mantener el foco.

Para qué sirve: Mejora la eficiencia personal mediante gestión de tareas, bloques de tiempo y seguimiento de hábitos.

Coste aproximado: Proyecto hecho con HTML, CSS y PHP, sin coste adicional.

  • Gestión de tareas y prioridades
  • Bloques de tiempo (time blocking)
  • Seguimiento de hábitos y estadísticas
